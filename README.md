# Downloads da Sora Works

Instaladores para Windows dos apps da Sora Works. Todos são gratuitos, sem anúncios e sem conta.

| App | O que faz | Versões |
|---|---|---|
| **Sora Gaming** | Monitor do PC com alertas de temperatura, notas, rotina de treino e cofre de senhas | tags `gaming-v…` |
| **Sora Converter** | Converte imagens, vídeos e áudios, tudo no seu PC | tags `converter-v…` |
| **Sora Cleaner** | Mostra o que ocupa o disco e faz uma limpeza rápida e segura | tags `cleaner-v…` |

## Como baixar

1. Abra a página [**Releases**](https://github.com/cleverquadros/sora-releases/releases).
2. Procure o app pelo nome e abra a versão mais recente dele.
3. Em **Assets**, baixe o arquivo `.exe` (instalador) ou o `.msi`.

Funciona no Windows 10 e 11, 64 bits.

> O Windows pode mostrar o aviso "O Windows protegeu o computador" na primeira vez, porque os
> instaladores ainda não têm assinatura digital. Clique em **Mais informações** e depois em
> **Executar assim mesmo**.

## Sobre este repositório

Aqui ficam só os instaladores. O código dos apps não é público e não está aqui.
Os arquivos são gerados e enviados automaticamente pelo processo de build de cada app.
